# Contributing to AgentFi SDK

Thank you for your interest in contributing to AgentFi SDK!

## Getting Started

1. Fork the repository
2. Clone your fork: git clone https://github.com/your-username/agentfi-sdk.git
3. Create a branch: git checkout -b feature/your-feature-name
4. Make your changes
5. Test your changes
6. Commit: git commit -m "Description of changes"
7. Push: git push origin feature/your-feature-name
8. Open a Pull Request

## Development Setup

See README.md for installation instructions.

## Code Standards

- Use TypeScript for all new code
- Follow existing code style
- Add tests for new features
- Update documentation as needed
- Keep commits atomic and well-described

## Testing

    cd api
    npm test

## Pull Request Guidelines

- Describe what your PR does
- Reference any related issues
- Include tests if applicable
- Ensure all tests pass
- Update documentation

## Reporting Issues

- Use GitHub Issues
- Describe the problem clearly
- Include reproduction steps
- Provide error messages/logs
- Specify your environment

## Questions?

- Email: support@agentfi.io
- Discord: https://discord.gg/agentfi

Thank you for contributing!
