## Project Goal

Enable AI trading bots to execute cross-chain swaps via NEAR Intents protocol.

## Core Principles

1. **Component-based** - Each service independently testable
2. **Minimal dependencies** - Only verified external endpoints
3. **Clear documentation** - Track all progress in git
4. **Test-first** - Write tests before implementation
